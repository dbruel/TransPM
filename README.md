# TransPM
Simulation study evaluating the transportability of (clinical) prediction models at the example of the UK DCD Risk Score.

## Repository structure

- code:
    - 01 - 05: Simulation runs with varying population characteristics.
    - 00: Script running the simulations 01 - 05.
    - 06: Script used for plotting the simulation results.
- results:
    - checks: R-Data used to validate population characteristics.
    - missingness: Missingness counts in the different simulation runs.
    - plots: Plots used for the evaluation of the simulations.
    - tables: html tables and R-Data of simulation results.
- PreReg: 
    - Pre-registration of the simulation study according to the ADEMP pre-registration template based on the publication by Siepe et al. (2024).

## References

Siepe, B. S., Bartoš, F., Morris, T. P., Boulesteix, A.-L., Heck, D. W., & Pawel, S.(2024). Simulation Studies for Methodological Research in Psychology: A Standardized Template for Planning, Preregistration, and Reporting. Psychological Methods.
